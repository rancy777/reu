# Code of Conduct

We want this project to be a rigorous and respectful research community.

Expected behavior:

- be respectful and constructive;
- distinguish facts, observations, hypotheses, and opinions;
- welcome corrections and reproducibility checks;
- avoid harassment, doxxing, credential disclosure, and unauthorized access;
- do not use project discussions to coordinate piracy, license bypass, credential theft, or attacks on real services.

Project maintainers may remove content or restrict participation when necessary to keep the project safe and research-focused.
