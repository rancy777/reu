# EC-002 — AAB / APK Set
Claim: AAB is a publishing format and device-specific APK sets are generated from it; package analysis should model modules/splits rather than treat AAB as a directly installable APK.
Source: Android Developers — App Bundle format
URL: https://developer.android.com/guide/app-bundle/app-bundle-format
Quality: S
Scope: current documentation; verify bundletool release details before operational use.
