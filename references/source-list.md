- Frida: official release index currently shows 17.23.x; 17.23.3 appears as the latest listed release in the 2026-10-16 research snapshot.
- Ghidra: official repository currently lists 12.1.4 as latest release in the research snapshot.
- x64dbg: several community MCP implementations are active; exact provider version must be resolved and pinned at installation.
- WinDbg: Microsoft public material documents MCP feature state/settings in current builds; third-party DbgEng MCP implementations expose more explicit tool contracts.
- Unidbg: project README documents MCP debugger/custom-tool support.
- Filesystem: official MCP reference server provides constrained local filesystem operations.
