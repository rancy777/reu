# Android Fundamentals

Track separately:
APK, AAB, split APK/APKS, DEX, ELF/SO, manifest/resources, Java/Kotlin, Smali, JNI, ClassLoader, ART, JIT, AOT.

AAB is a publishing format; installation commonly involves generated APK sets and device configuration.

ART uses a hybrid execution model including interpretation, JIT and AOT; runtime behavior changes by Android release and compilation/profile state.

Android version/API
ABI
device/emulator
root/non-root
debuggable state
Frida/server/Gadget versions
target package/version
split/module inventory
