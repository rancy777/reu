# Anti-Analysis Knowledge Base

## Windows
Debugger APIs, PEB/TEB checks, NtQueryInformationProcess, debug registers, timing, exceptions, TLS callbacks, API hashing/dynamic resolution, integrity checks, anti-VM, module/process/handle checks, parent/environment checks.

## Android
debuggable/JDWP checks, ptrace/TracerPid, /proc inspection, maps/module inspection, Frida/hook indicators, root/emulator/package/port checks, integrity checks.

## Required representation
Detection mechanism
→ observable artifact
→ analysis implication
→ authorized research approach
→ limitations

Never label a mechanism as a universal bypass. Detection can be layered, version-specific, or incidental.
